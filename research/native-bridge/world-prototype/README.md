# Експериментальний Rust-прототип тайла

Автономна перевірка конвеєра на захоплених клітинках тайла. Це не інтеграція
в BeamNG, не повний порт `generator.lua` і не доказ прискорення гри.

## Запуск

Потрібен fixture з `capture_road_fixture.py`, розпакований у JSON. Наприклад:

```powershell
python -c "import gzip,shutil; s=gzip.open('out/native-bridge-road-route-20261116/kyiv-road-fixture.json.gz','rb'); d=open('out/world-prototype-input.json','xb'); shutil.copyfileobj(s,d); d.close(); s.close()"
cargo run --release --manifest-path research/native-bridge/world-prototype/Cargo.toml -- out/world-prototype-input.json out/world-prototype-output.json
cargo test --release --manifest-path research/native-bridge/world-prototype/Cargo.toml
```

Програма не перезаписує вихідний файл. `RAYON_NUM_THREADS` обмежує кількість
потоків. JSON містить `tile`, `roads` і `buildings` (трикутники XYZ), `trees`
(позиції нанесених дерев XYZ). Координати — метри в системі клітинки паку;
це не формат сцени рушія.

## Розподіл роботи та межі

Прототип також читає `cells` і `options.tileSize` із захоплення
`capture_tile_input.py` та відсіває повтори за ідентифікатором. Він читає лише
дороги, будівлі й точки; інші частини повного входу ще не використовуються.
Незалежні дорожні смуги й корпуси будинків обчислюються паралельно; потім
нанесені точки дерев перевіряються проти доріг і контурів будівель з отворами.
Порядок результатів не залежить від кількості потоків. Плоский дах використовує
копію `roofs.rs` із сусіднього стенда; її алгоритм окремо звірено з Lua.

Це приблизна перевірка зайнятості, не повна маска EarthNG: вона не враховує
воду, покриття, тротуари, меблі, рівні мостів чи межі крон. Смуги складаються
з окремих сегментів без стикування, а їхня ширина може виходити за тайл. Дах
відбирає смуги за прямокутником, але не обрізає трикутники повністю. Висота
будинку наближена; фасади та похилі дахи не відтворені. Дерева не мають моделей,
масштабу чи правил біому, нові дерева і трава не розсіюються. Одна клітинка
не містить усіх сусідніх даних для швів. Результат не можна використовувати
в грі як заміну генератора.

Наступний крок — спільний з Lua повний вхід і правила, пакетування та перевірка
повного результату. У Lua мають лишитися керування життєвим циклом тайла та
виклики BeamNG для сцени, Forest, колізії й навігації. Експериментальний міст
із сусідніх файлів не має релізного життєвого циклу та захисту і тут не запускається.
