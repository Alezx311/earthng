# EarthNG.exe — один файл для встановлення моду і збірки карт

Стан на 2026-11-08, гілка `feature/mapbuilder-rs`. Рішення користувача (8.11):

- **Один exe на Rust із вшитим Python.** Гравець нічого не встановлює: ні Python, ні Tk, ні pip.
- **Інтерфейс — веб-сторінка у вікні WebView2** (є у Windows 10/11). Карта для вибору області,
  налаштування, прогрес. Згодом тут же редагування карти перед збиранням у zip.
- **Тайли:** поки лише абстракція джерела. Окремого сервера зараз немає. Робоче джерело —
  PBF Geofabrik: найменший регіон, що покриває виділення, і вже нарізані тайли з кешу.

Нинішній шлях (Python 3.13 з Tk → розпакувати ZIP → `MapBuilder.bat` → `Setup.bat` з pip) лишається
для розробки й запасним, доки exe не замінить його в релізі.

## Як влаштований exe

```
EarthNG.exe  (rust/crates/app)
├─ вікно tao + wry (WebView2), сторінка з app/ui/ вшита в exe (протокол earthng://)
├─ earthng://tile/z/x/y — тайли OSM для підкладки через Rust: свій User-Agent, кеш на диску
├─ runtime: ZIP, дописаний у кінець exe; при першому запуску розпаковується в
│  %LOCALAPPDATA%\EarthNG\runtime\<sha256 ZIP>\ (наступні запуски — без розпаковки)
│    python\        вбудований CPython 3.13 (python-3.13.x-embed-amd64) + site-packages
│    earthng\       Python-конвеєр (ті ж файли, що в ZIP MapBuilder: prepare_release.builder_files)
│    mod\           Lua планети (для «оновити код планети»)
│    bin\           earthng-mapbuilder.exe, earthng_native.dll
└─ сервіс: python\python.exe earthng\app_service.py — JSON-рядки через stdin/stdout
```

Дані (PBF, тайли, DEM, індекси, готові паки) живуть не в runtime (він версійний), а в
`%LOCALAPPDATA%\EarthNG\data` або теці, яку обрав користувач: змінна `EARTHNG_HOME` для Python.
У checkout без неї все лишається як було (`ROOT`).

Режим розробки: exe, запущений із `rust/target`, бере Python з `.venv` і код із checkout, а
сторінку з `app/ui/` на диску (правки без перезбірки Rust).

## Протокол сторінка ↔ сервіс

Сторінка шле `{"id": n, "cmd": "...", ...}`, сервіс відповідає `{"id": n, "ok": true, ...}` або
`{"id": n, "ok": false, "error": "..."}`. Події без `id`: `{"event": "log" | "stage" | "done", ...}`.

| Команда | Що робить |
| --- | --- |
| `status` | Тека користувача BeamNG (знайдена чи обрана), чи встановлена планета і якої версії, версія exe, вільне місце |
| `set_game_folder` | Обрати іншу теку користувача BeamNG |
| `install_planet` | Завантажити `earthng_planet.zip` з GitHub Release у `mods` (з продовженням обриву) |
| `places` | Пошук країн і регіонів Geofabrik |
| `estimate` | Розмір завантаження, клітинки, час — для виділення і налаштувань |
| `build` | Зібрати пак області (місце або бокс, вигляд, шари) і встановити в `mods`; події `stage`/`log` |
| `stop` | Зупинити збірку (наступна продовжить з місця) |
| `project_save` / `project_load` | Проєкт карти: виділення, налаштування, правки (див. нижче) |

## Проєкт карти і правки перед zip

`<home>/projects/<id>/project.json`:

```json
{"schema": "earthng-project-v1", "id": "kyiv-centre", "title": "Київ, центр",
 "selection": {"place": "ukraine", "box": [30.40, 50.38, 30.62, 50.52]},
 "options": {"look": {...}, "include": {...}},
 "edits": []}
```

`edits` — шар правок поверх OSM, який сторінка вже може малювати і зберігати. Застосування в
пак (додати/прибрати об'єкт, змінити тег) — наступний етап: правки йдуть у тайли перед індексом,
тож генератор у грі нічого про них не знає. Формат правок не змішувати з джерелом: тайли OSM
лишаються тими самими байтами, правки — окремий файл із версією схеми.

## Джерело тайлів

`tile_source` у Python: «дай тайли для області». Зараз одна реалізація — Geofabrik + нарізка
(`country_fetch.cut_tiles`, `tiles_from_cover`). Сервер із готовими тайлами (sha256 кожного тайла
вже є в `index.json`) згодом стане другою реалізацією з тим самим контрактом.

## Порядок робіт

1. Нарізка без втрат на краях (`osm_tiles.region_keys`) — зроблено 8.11.
2. `EARTHNG_HOME`: дані окремо від коду.
3. `app_service.py` + тести протоколу.
4. `rust/crates/app`: вікно, сторінка, тайли підкладки, сервіс, розпаковка runtime.
5. Сторінка: гра і планета, вибір області, налаштування, збірка, прогрес.
6. `prepare_app.py`: зібрати runtime (вбудований Python + колеса + код + bin) і дописати в exe.
7. Перевірка з чистого профілю Windows-користувача: exe → планета → пак міста → гра.
