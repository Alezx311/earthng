# EarthNG.exe — один файл для встановлення моду і збірки карт

Стан на 2026-11-08: вийшов у релізі 0.8.0, код у `master`. Рішення користувача (8.11):

- **Один exe на Rust із вшитим Python.** Гравець нічого не встановлює: ні Python, ні Tk, ні pip.
- **Інтерфейс — веб-сторінка у вікні WebView2** (є у Windows 10/11). Карта для вибору області,
  налаштування, прогрес. Згодом тут же редагування карти перед збиранням у zip.
- **Тайли:** поки лише абстракція джерела. Окремого сервера зараз немає. Виділення спершу
  береться з Overpass (лише ця область); якщо Overpass не відповідає або область завелика —
  сторінка питає дозволу завантажити PBF Geofabrik, показує розмір і час (див. «Джерело тайлів»).

Старий шлях (Python 3.13 з Tk → розпакувати ZIP → `MapBuilder.bat` → `Setup.bat` з pip) видалено 8.11
разом із Tk-вікном. Реліз (`prepare_release.py`) кладе EarthNG.exe замість EarthNG-MapBuilder.zip; у
runtime exe є `earthng/ready_packs.json` з готовими паками релізу — для кнопки «готові карти», яку ще
треба додати на сторінку. Також ще немає прев'ю вигляду й «оновити код планети»
(`country_fetch.refresh_planet` лишився в CLI).

## Як влаштований exe

```
EarthNG.exe  (rust/crates/app)
├─ вікно tao + wry (WebView2), сторінка з app/ui/ вшита в exe (протокол earthng://)
├─ earthng://tile/z/x/y — тайли OSM для підкладки через Rust: свій User-Agent, кеш на диску
├─ runtime: ZIP, дописаний у кінець exe; при першому запуску розпаковується в
│  %LOCALAPPDATA%\EarthNG\runtime\<sha256 ZIP>\ (наступні запуски — без розпаковки)
│    python\        вбудований CPython 3.13 (python-3.13.x-embed-amd64) + site-packages
│    earthng\       Python-конвеєр (prepare_release.builder_files)
│    mod\           Lua планети (для «оновити код планети»)
│    bin\           earthng-mapbuilder.exe, earthng_native.dll
└─ сервіс: python\python.exe earthng\app_service.py — JSON-рядки через stdin/stdout
```

Сервіс одразу забирає собі копії stdin/stdout, а fd 0 і 1 переводить на NUL і в лог
(`protocol_streams`). Причина: дочірній Python, що успадкував stdin-pipe, на старті робить
`lseek` на ньому, а Windows тримає цей запит, доки не повернеться читання, яке головний потік
сервісу вже чекає на тому ж pipe. Індекс і `Map detail` висіли б, доки сторінка не надішле
наступну команду (знайдено 8.11 на першій збірці з вбудованим runtime; тест
`test_a_child_starts_while_the_page_pipe_has_a_read_pending`).

Дані (PBF, тайли, DEM, індекси, готові паки) живуть не в runtime (він версійний), а в
`%LOCALAPPDATA%\EarthNG\data` або теці, яку обрав користувач: змінна `EARTHNG_HOME` для Python.
У checkout без неї все лишається як було (`ROOT`).

Режим розробки: exe, запущений із `rust/target`, бере Python з `.venv` і код із checkout, а
сторінку з `app/ui/` на диску (правки без перезбірки Rust).

## Протокол сторінка ↔ сервіс

Сторінка шле `{"id": n, "cmd": "...", ...}`, сервіс відповідає `{"id": n, "ok": true, ...}` або
`{"id": n, "ok": false, "error": "..."}`. Події без `id`: `{"event": "log" | "stage" | "done", ...}`.

| Команда | Що робить |
| --- | --- |
| `status` | Тека користувача BeamNG (знайдена чи обрана), чи встановлена планета і якої версії, версія exe, вільне місце |
| `set_game_folder` | Обрати іншу теку користувача BeamNG |
| `install_planet` | Завантажити `earthng_planet.zip` з GitHub Release у `mods` (з продовженням обриву). Окремо потрібна рідко: `build` ставить планету сам |
| `places` | Пошук країн і регіонів Geofabrik (локально, на кожне введення) |
| `geocode` | Міста й адреси з Nominatim OSM — лише по Enter, не частіше разу на секунду, свій User-Agent; окремий потік, щоб не тримати `status`/`stop` |
| `covering` | Найменший регіон Geofabrik, що покриває бокс |
| `estimate` | Розмір завантаження, клітинки, час — для виділення і налаштувань; `source`: `tiles` (вже нарізано), `overpass`, `pbf`; `pbf_seconds` — завантаження й нарізка PBF для картки дозволу; `ask_pbf` — великий PBF, якого немає на диску і який потрібен ще до спроби Overpass (сторінка питає одразу) |
| `build` | Зібрати пак області (місце або бокс, вигляд, шари, `allow_pbf`) і встановити в `mods`; події `stage`/`log`. Якщо планети немає, вона старша за очікувану чи не читається, першим етапом `Planet` ставиться з GitHub. Без `allow_pbf` бокс береться з Overpass; якщо жоден сервер не дав повної відповіді — `done` з `result: "needs_pbf"`, `reason`, `name`, `pbf_bytes`, `pbf_seconds` |
| `stop` | Зупинити збірку (наступна продовжить з місця) |
| `project_save` / `project_load` | Проєкт карти: виділення, налаштування, правки (див. нижче) |

## Сторінка: один шлях від exe до гри

1. Зверху стан: гра знайдена (або «вказати» → Налаштування) і мод EarthNG: встановлено / встановиться з
   першою картою / оновиться з картою (`planet_needed`: missing, old, unreadable).
2. «Оберіть область»: пошук міста (Enter, Nominatim) або велика кнопка «Обвести область на мапі».
   Місто з пошуку одразу стає виділенням і дає назву карті.
3. Картка області: площа, дані (регіон Geofabrik; «лише ця область з Overpass» або «файл країни N МБ»), час; примітки (мод
   встановиться першим, велика область, немає теки гри) і кнопка «Створити карту». Вигляд, шари,
   назва проєкту й правки — у згорнутих блоках.
3а. «Потрібен файл даних країни»: Overpass не відповів (причина дрібно) або область завелика / цілий
   регіон з великим файлом (тоді картка ще до збірки, `ask_pbf`). Маленький файл країни не питається. Файл, розмір, час завантаження й нарізки, «файл залишиться на
   диску»; «Завантажити й створити карту» (`build` з `allow_pbf`) або «Назад».
4. Збірка: смуга прогресу за оцінкою етапів, список етапів, журнал згорнутий (розгортається при помилці),
   «Зупинити» / «Спробувати ще раз».
5. «Карту встановлено»: що відкрити в грі (Freeroam → EarthNG - Planet), «Запустити BeamNG.drive»
   (`steam://rungameid/284160`, єдиний не-https URL, який відкриває exe), тека mods, «Створити ще одну».

## Проєкт карти і правки перед zip

`<home>/projects/<id>/project.json`:

```json
{"schema": "earthng-project-v1", "id": "kyiv-centre", "title": "Київ, центр",
 "selection": {"place": "ukraine", "box": [30.40, 50.38, 30.62, 50.52]},
 "options": {"look": {...}, "include": {...}},
 "edits": []}
```

`edits` — шар правок поверх OSM, який сторінка вже може малювати і зберігати. Застосування в
пак (додати/прибрати об'єкт, змінити тег) — наступний етап: правки йдуть у тайли перед індексом,
тож генератор у грі нічого про них не знає. Формат правок не змішувати з джерелом: тайли OSM
лишаються тими самими байтами, правки — окремий файл із версією схеми.

## Джерело тайлів

`country_fetch.tile_source(root, place, box, allow_pbf)` — «дай тайли для області», дві реалізації
з одним контрактом (`pbf`, `tiles`, `ready`, `fetch`, `cut`):

- **`OverpassSource`** — бокс без PBF країни на диску. Запит бере те, що лишила б нарізка
  (`osm_tiles.cut`): усі node і way у клітинках виділення з буфером (`overpass_box`), multipolygon,
  restriction і relation-орієнтири (`osm_select.LANDMARK_TAGS`) з членом у рамці, орієнтири й
  multipolygon, що їх містять (`rel(br.r)`), і все це до останнього node (`>>`). XML пишеться в
  маленький PBF `data/overpass/<slug>-<sha1 боксу>.osm.pbf` з рамкою в заголовку, і далі його ріже
  той самий `cut_tiles` — тайли ті самі байти, що з PBF країни (`test_overpass`, на фікстурі з
  виходом за межі пакета, вкладеним орієнтиром і неповним restriction). Той PBF читає й `Map detail`.
  Сервери: overpass-api.de, overpass.private.coffee, overpass.kumi.systems. Спершу всім одразу
  крихітний запит (`overpass_alive`, `node(1);out ids;`) з межею 10 с на всіх (`OVERPASS_PROBE`):
  сервер, що не відповів (502 «черга повна» або тиша), не питається; жоден не відповів — `NeedsPbf`
  через 10 с, а не через хвилини (9.11 так поводилися всі три). Живі — по черзі, найшвидший першим,
  240 с на спроби, 150 с тиші на сервер (черга, запит, завислий потік; сам потік може тривати хвилинами). Відповідь
  без `</osm>` чи з `runtime error`/`runtime remark` — відмова. Площа рамки понад 300 км² (клітинки
  з буфером: 2 × 2 км міста — уже 46–66 км²) одразу `NeedsPbf`.
- **`GeofabrikSource`** — цілий регіон, PBF уже на диску (`data/pbf/<slug>.osm.pbf`, зберігається для
  наступних карт), маленький PBF (до 100 МБ, `SMALL_PBF_BYTES`: Албанія 52 МБ качається й ріжеться
  за ~25 с, швидше за відповідь Overpass — береться одразу і без питань, рішення користувача 8.11)
  або дозвіл користувача (`allow_pbf`). Тайли з кешу і `tiles_from_cover` — в обох.

8.11 вдень усі три сервери Overpass давали 502/504 або мовчали навіть на 3 × 3 км; саме тому збірка
не падає, а питає про PBF. Сервер із готовими тайлами (sha256 кожного тайла вже є в `index.json`)
згодом стане третьою реалізацією.
